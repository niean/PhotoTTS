隐私政策

适用产品：拍照阅读（PhotoTTS）  |  最后更新：2026年3月27日

感谢您使用拍照阅读（PhotoTTS，以下简称"本应用"或"我们"）。 本应用面向3至10岁儿童及其家长，帮助将绘本图片转换为语音播放。 我们高度重视用户（尤其是儿童）的个人信息与隐私安全，本隐私政策将说明我们如何收集、使用和保护您的信息。

本应用面向儿童群体使用。家长或监护人在允许儿童使用前，请仔细阅读本隐私政策。

一、我们收集哪些信息

本应用仅收集为实现核心功能所必需的最少量信息。

信息类型 收集方式 用途 是否上传至外部
绘本图片 用户拍摄或从相册选择 OCR 文字识别 是（仅用于识别，见第三条）
会话记录 应用自动生成 保存识别结果与音频，供回放使用 否，仅存本地
API 密钥 用户手动填写 调用第三方 OCR/TTS 服务 否，仅存设备 Keychain
身份名称 用户可选填写 个性化显示，不与账号绑定 否，仅存本地
设备传输数据 用户主动发起设备间传输 在两台设备之间直接传输绘本记录 否，仅在本地网络内点对点传输，不经过任何服务器

我们不收集：姓名、手机号、邮箱地址、位置信息、设备标识符（如 IDFA）、行为追踪数据等任何可直接识别身份的个人信息。

二、我们申请哪些系统权限

系统权限 申请原因 是否可拒绝
相机（Camera） 拍摄绘本图片，进行 OCR 识别 可拒绝，拒绝后无法使用拍照功能，可改为从相册选图
照片图库（Photo Library） 从相册选择绘本图片 可拒绝，拒绝后无法从相册选图，可改为使用拍照功能
本地网络（Local Network） 在两台设备之间通过本地 Wi-Fi 网络直接传输绘本记录（基于 Apple MultipeerConnectivity 框架） 可拒绝，拒绝后无法使用设备间传输功能，可改为文件导出/导入方式

所有权限均仅在您主动执行对应操作时使用，不在后台持续访问。

三、我们如何使用第三方服务

本应用依赖以下第三方 API 实现核心功能。图片在发送前会自动降采样至最大边长 2048 像素，以减少传输数据量。所有通信均使用 HTTPS 加密。

服务 提供方 用途 数据类型
OCR 文字识别 火山引擎（字节跳动） 从绘本图片中识别文字 降采样后的图片
语音合成（TTS） 火山引擎（字节跳动） 将识别文字合成为语音 文字内容
语音合成（TTS） 阿里云（通义） 将识别文字合成为语音（备选） 文字内容

图片与文字仅用于完成当次识别/合成请求，我们无法控制第三方服务提供商对数据的处理方式。 建议您查阅各服务商的隐私政策：

  • 火山引擎隐私政策
  • 阿里云隐私政策
第三方 API 密钥由您自行配置，存储在设备 Keychain 中，本应用不会向任何服务器传输您的 API 密钥。

四、数据存储与保留

本应用不设任何服务器账号，不将用户数据同步至云端。所有会话记录、图片、音频文件均仅存储在您的设备本地。
  • 会话数据（图片、音频、识别文字）存储于设备本地 Documents/Sessions/ 目录，不会自动备份至外部。
  • 您可随时在应用内删除任意会话记录，删除后数据不可恢复。
  • 设备间传输功能通过本地 Wi-Fi 网络点对点传输（Apple MultipeerConnectivity），数据不经过任何外部服务器。
  • 卸载应用后，设备上的所有应用数据将被系统清除。

五、儿童隐私保护

本应用的主要使用对象为13岁以下儿童（Children Under 13）。我们遵守相关儿童个人信息保护规定，具体做法如下：

  • 不收集任何可识别儿童身份的个人信息（无注册、无账号、无用户画像）。
  • 不展示定向广告，不设应用内购买。
  • 不接入任何第三方广告 SDK 或行为分析 SDK。
  • 所有数据处理均在设备本地完成，仅在识别/合成时将内容发送至第三方 API，发送内容不包含儿童个人信息。

家长或监护人对儿童使用本应用拥有最终控制权。如您希望删除设备上存储的所有会话数据，可在应用内逐一删除，或直接卸载应用。

六、安全措施

  • API 密钥统一存储于 iOS 系统 Keychain，不写入日志或其他明文存储。
  • 所有对外网络请求强制使用 HTTPS，不降级至 HTTP。
  • 图片在发送至外部 API 前自动降采样（最大边长 2048 像素），减少敏感内容暴露。
  • 应用内不包含任何追踪代码或第三方统计 SDK。
  • 设备间传输基于 Apple MultipeerConnectivity 框架，数据仅在本地 Wi-Fi 网络内点对点传输，不经过外部服务器。

七、您的权利

由于本应用不收集账号信息、不使用云端存储，您对数据拥有完全控制权：

  • 查看：所有会话数据均可在应用内直接查看。
  • 删除：可在应用内删除任意或全部会话记录。
  • 撤回权限：可随时在 iPhone「设置 - 隐私与安全性」中撤回相机或相册权限。
  • 清除所有数据：卸载应用即可清除设备上存储的全部应用数据。

八、隐私政策的变更

若我们对本隐私政策进行实质性修改，将通过应用内通知或在本页面更新"最后更新"日期的方式告知您。 建议您定期查阅本页面。继续使用本应用，视为您同意更新后的隐私政策。

如您对本隐私政策有任何疑问，请通过以下方式联系我们：
