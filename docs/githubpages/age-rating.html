一、产品概述

拍照阅读（PhotoTTS）是一款面向 3 至 10 岁儿童及其家长的教育类工具应用。 核心功能是将绘本图片通过 OCR 识别文字，再由 TTS 合成语音播放，帮助儿童听读绘本故事。

本应用建议年龄分级为 4+，适合所有年龄段用户使用，不包含任何不适宜儿童的内容。

五、儿童数据保护

本应用高度重视儿童隐私保护，具体措施如下：

  • 不收集任何可识别儿童身份的个人信息（无注册、无账号、无用户画像）
  • 所有用户数据（图片、音频、会话记录）仅存储在设备本地，不上传至任何服务器
  • API 密钥存储于 iOS 系统 Keychain，通过 HTTPS 加密传输
  • 图片在发送至第三方 OCR 服务前，自动降采样至最大 2048 像素
  • 设备间传输通过本地 Wi-Fi 网络点对点完成，不经过任何外部服务器
  • 卸载应用即可清除设备上的所有应用数据

完整隐私政策请参阅：隐私政策

六、家长指引

  • 本应用需要使用相机或相册权限拍摄/选择绘本图片，建议家长协助儿童完成拍照操作
  • OCR 文字识别和 TTS 语音合成依赖第三方云服务，需要网络连接
  • 第三方服务的 API 密钥需由家长配置，儿童无需接触密钥信息
  • 应用支持通过本地 Wi-Fi 在设备间传输绘本记录，需要本地网络权限，数据不经过外部服务器
  • 建议家长根据儿童年龄，合理控制每次使用时长
