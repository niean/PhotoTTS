# Photo TTS - iOS APP 项目规划

## 项目概述
Photo TTS - 一个基于iOS的智能拍照文字转语音阅读应用，专为7-12岁学生设计

## 核心功能模块

### 1. 拍照模块
- 相机功能
  - 实时预览
  - 自动对焦
  - 闪光灯控制
  - 拍照按钮
  - 相册选择功能
- 批量拍照功能
  - 每次拍摄1张照片
  - 允许多次拍照，最多累计100张
  - 照片计数显示和预览
  - 单张删除和重拍功能
  - 多张照片准备好后，一次性批量上传给豆包API

### 2. 图像转语音模块
- 图像预处理
  - 图像压缩和格式转换
  - 自动裁剪和角度校正
  - 图像质量优化
- 文字识别阶段
  - 调用豆包大模型OCR API进行文字识别
  - 支持单张和批量图片处理
  - 多张照片准备好后，一次性批量上传给豆包OCR API
  - 大模型自动识别图片中的文字内容
  - 支持多语言识别（中文、英文等）
  - 错误处理和重试机制
- 文字转语音阶段
  - 调用豆包大模型TTS API进行语音合成
  - 将识别出的文字转换为语音
  - 支持多种语音参数设置（语速、音调、音量、语音类型）
  - 支持多语言语音合成
  - 错误处理和重试机制
- 音频播放控制
  - 播放/暂停/停止/快进/快退
  - 进度条显示（彩色进度条）
  - 音频缓存管理
  - 批量音频播放队列管理

## 技术架构

### 前端 (iOS)
- 开发语言: Swift 5.0+
- 最低支持版本: iOS 14.0+
- 架构模式: MVVM + Coordinator
- UI框架: SwiftUI + UIKit混合使用
- 依赖管理: Swift Package Manager
- 设计风格: 儿童友好、卡通化、色彩丰富

### 核心框架
- 相机: AVFoundation
- 图像处理: Core Image
- 网络请求: URLSession
- 音频播放: AVFoundation
- 数据存储: Core Data
- JSON解析: Codable
- 权限管理: 相机、相册权限

### 第三方库
- 网络请求: Alamofire (可选，简化HTTP请求)
- UI组件: SnapKit (布局)
- 权限管理: PermissionScope
- 图像处理: SDWebImage (可选，图像缓存)
- 动画效果: Lottie (可选，卡通动画)

## 风险评估

### 技术风险
- API稳定性: 依赖豆包大模型OCR和TTS API的稳定性
- 网络延迟: 需要处理两个阶段网络请求的延迟和失败
- API限制: 需要了解豆包OCR和TTS API的调用频率和额度限制
- 图片大小限制: 需要了解OCR API对图片大小和格式的要求
- 批量上传性能: 100张图片的批量上传需要处理网络稳定性
- API批量处理限制: 需要了解豆包OCR API的批量处理能力
- 两阶段处理: OCR和TTS两个阶段需要协调处理，增加复杂性

### 解决方案
- 实现API请求重试机制和错误处理
- 添加网络状态检测和离线提示
- 实现图片压缩和格式转换
- 异步处理，显示加载进度
- 本地缓存音频结果
- 实现批量上传的队列管理和进度控制
- 分批上传大量图片，避免网络超时
- 实现断点续传功能

## 总结

这个项目预计总开发时间为7-10周，是一个中等复杂度的iOS阅读应用。通过调用豆包大模型OCR API和TTS API实现图片到语音的两阶段转换，支持批量处理最多100张照片，专为7-12岁学生设计。主要挑战在于儿童友好的界面设计、阅读功能的完善、家长控制功能的实现，以及两个阶段网络请求的协调处理和稳定性。
