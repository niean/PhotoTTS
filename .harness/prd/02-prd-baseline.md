# 产品需求 - 稳定固化(不频繁变更)

## 1. 极简摘要

- 产品：PhotoTTS（拍照阅读）— 拍照/选图 → OCR → LLM → TTS → 保存 → 播放。
- 用户：3～10 岁儿童及家长，场景为纸质绘本听读与重复收听。
- 结构：底导四个功能Tab（首页、制作、管理、我的）。首页 = 制作入口 + 会话记录列表，点击记录在首页全屏 PlayView 播放；制作 Tab = 拍照/选图或加载已有记录 → 按需执行 OCR / LLM / TTS → 保存，播放统一用 PlayView 全屏；管理 Tab = 记录管理（查看/编辑/删除）。
- 核心流程：制作（新建或加载已有记录，按需从 OCR / LLM / TTS 继续） → 保存记录 → 播放 → 重复播放。

产品定位、体验原则与判断准则见 ./01-prd-sense.md。

## 2. 页面结构

加载页 → 主界面（全屏：播放 / 相机；底导：首页、制作、管理、我的）；各 Tab 内为顶导 + 手势区 + 内容。页面结构如下，

- 全屏容器
    - 启动页
    - 播放(大图)
    - 相机
- 顶状态栏
- 底导Tab
    - 首页
    - 制作
    - 管理
    - 我的
        - ${常规页面}/画布(CustomZStack)
            - ${内容}
            - 顶导
            - 左导(手势识别)

## 3. 页面风格

### 3.1 颜色体系

采用 SwiftUI 语义色为主，自动适配浅色/深色模式：

| 层级 | 颜色 | 用途 |
|------|------|------|
| 主文字 | `.primary` | 导航标题、卡片名称、正文 |
| 次文字 | `.secondary` | 副标题、元数据、提示文字 |
| 辅助文字 | `.tertiary` / `.gray` | 占位符、空状态图标、禁用态 |
| 强调蓝 | `.blue` | 主操作按钮、链接、选中态 |
| 成功绿 | `.green` | 开始按钮、成功状态 |
| 警告橙 | `.orange` | 警告状态 |
| 危险红 | `.red` | 删除操作、错误状态 |
| 护眼绿 | `Color(red:0.85, green:0.95, blue:0.88)` | PlayView 护眼模式背景 |
| 进度绿 | `Color(red:0.4, green:0.85, blue:0.55)` | 播放进度条填充 |

### 3.2 背景

| 场景 | 背景色 |
|------|--------|
| 页面主背景 | `Color(.systemBackground)` |
| 分组页面背景 | `Color(.systemGroupedBackground)` |
| 卡片/分区 | `Color(.secondarySystemGroupedBackground)` 或白色 |
| 搜索栏 | `Color(.systemGray6)` |
| 编辑器/详情分区 | `Color(.systemGray5)` |
| 模态遮罩 | `Color.black.opacity(0.3~0.5)` |
| 播放器全屏 | systemBackground 或护眼绿 |

### 3.3 字体

全项目字体统一通过 `Constants.Fonts` 引用，禁止硬编码。

- 语义字体：使用系统 Text Style（largeTitle / headline / body / caption 等），跟随系统动态字体
- 自适应字体：通过 `DeviceScale.adaptiveSize(iPhone:)` 缩放，iPad 按 1.25x 放大
- 等宽字体：计时器、配置编辑器使用 monospaced design
- 导航标题：17pt semibold；导航按钮：16pt medium；正文：系统 body；元数据/标签：12pt

### 3.4 圆角

| 值 | 典型用途 |
|----|---------|
| 4~6pt | 小元素（缩略图、小按钮、倍速按钮） |
| 8pt | 中等元素（设置项、面板、缩略图） |
| 10pt | 搜索栏 |
| 12pt | 通用卡片、详情分区、报告卡片、历史卡片 |
| 14pt | 首页网格卡片 |
| 半高 | 进度条（pill 形状） |

### 3.5 阴影与边框

- 卡片阴影：`shadow(color: .black.opacity(0.08), radius: 4, x: 0, y: 2)` -- 轻薄投影
- 播放器控件：`shadow(color: .black.opacity(0.5), radius: 3)` -- 在图片上保证可读性
- 选中边框：`stroke(Color.blue, lineWidth: 2)`
- 未选中边框：`stroke(Color.gray.opacity(0.3), lineWidth: 1)`
- 分割线：`Color(.systemGray4)` lineWidth 0.5pt

### 3.6 间距

| 场景 | 水平 | 垂直 |
|------|------|------|
| 页面边距 | 16~20pt | 16~20pt |
| 卡片网格间距 | 12pt | 12pt |
| 卡片内边距 | 10pt | 8~12pt |
| 搜索栏内边距 | 10pt | 8pt |
| 分区内间距 | 12~16pt | 8~16pt |
| 空状态居中 | -- | 40pt |

所有间距通过 `DeviceScale.adaptiveSize(iPhone:)` 适配 iPad。

### 3.7 设备适配

- iPhone / iPad 使用统一缩放比例 `Constants.DeviceScale.iPadScale`（1.25x）
- 字体、间距、图标尺寸均通过 `adaptiveSize(iPhone:)` 或 `scaled()` 适配
- 首页网格列数：iPhone 2列、iPad 3列
- 分页条数：iPhone 20条、iPad 30条

## 4. 功能需求

### 4.1 全屏
- 全屏：播放统一在 PlayView 全屏（护眼底、大图、进度与操作栏）；控制层含底部播放控制区和顶部控制栏；播放设置按钮（齿轮图标）位于右下角，关闭按钮位于右上角；播放设置面板默认隐藏，点击设置按钮后展示，紧贴上边缘、支持上下滚动。支持双击切换暂停/播放；播放时禁止手动左右滑页，暂停时允许；暂停滑动图片后再播放，音频从当前图片对应位置开始。支持滑动手势调整音量和亮度。进度条支持播放状态拖拽和点击跳转。支持倍速播放（x0.9/x1/x1.1/x1.25/x1.5），在播放设置面板选择，每行最多3个选项、支持多行，即时生效，持久化记忆。支持计划内连播：仅当首页播放计划开启且当前记录属于当日计划时，才按计划队列自动连播；其它记录默认单条播放。两集间展示 3 秒过渡页（横向文字+播放进度如"2/5：记录名称"）；播放器内提供"计划内连播"开关，默认开启；连播进度如"(2/5)"展示在播放器中。相机为全屏 overlay，拍完图加入列表不退出。

### 4.2 底导
- 底导：首页、制作、管理、我的；全屏仅播放(PlayView)与相机 overlay 时遮盖底导。

### 4.3 首页（记录）
- 顶导：标题「首页」。
- 制作入口：拍照制作、选图制作；入口位于管理Tab上方，点击后切到制作 Tab，并打开相机或选图（选图为全屏弹窗）。
- 会话记录：双列卡片网格布局（iPad每行3个），卡片使用封面图片（width:height=16:9，根据屏幕宽度和每行卡片数计算尺寸，封面预生成仅第1张图片）、名称去掉日期前缀（仅展示播放按钮，不展示更多按钮）；卡片图片左下角展示日期（MM.dd格式，取名称前缀中的日期）和播放次数（格式如`04.01/2`），未播放过则仅展示日期无次数；点击某条 → 在首页全屏弹出 PlayView 播放（不切制作 Tab）；关闭 PlayView 后仍在首页。
- 播放计划：含最近30天内未播放记录的最早日期作为待办日期（每日最多一个），该日期下的未播放记录置顶展示、卡片底色为浅黄色；播放计划可在"我的-播放设置"中整体关闭；听完当日计划后不自动切换新日期。
- 默认绘本：内置示例绘本，除播放外不允许任何其它操作（编辑、删除等），不出现在播放历史和制作历史中。
- 记录搜索：支持按名称模糊搜索，搜索框内嵌系列筛选（左侧下拉菜单，系列选项预生成，默认不设置）；搜索框在列表顶部、随列表滚动、默认隐藏需下拉露出。
- 记录列表：改为单页懒加载，懒加载批量长度沿用原分页长度（iPhone 20 条，iPad 30 条），不显示底部分页切换控件。
- 记录播放入口使用播放图标。
- 拍照/选图从首页发起：若结果为空或取消，关闭后自动回到首页。

### 4.4 制作
- 顶导：标题「制作」；常规状态下右上角展示更多菜单（拍照、保存、删除，以及按状态可执行的 OCR / LLM / TTS 入口）；制作进行中不展示更多菜单，改为展示取消按钮。
- 制作：拍照制作、选图制作（与管理Tab入口一致）；选图用 MultiImagePicker，完成后写入当前页。制作阶段为 OCR→LLM→TTS：OCR/LLM（支持豆包、OpenAI Compatible，通过配置文件切换）+ TTS（支持火山引擎、阿里千问，通过配置文件切换）。制作过程展示中间产物（OCR文本、LLM汇总），进度条和状态固定在顶部；OCR 阶段逐批展示识别结果（张数/字数/耗时），LLM 完成后展示分析结果（字数/耗时）。支持从记录管理加载已有记录到制作页，仅恢复完整制作状态，不自动触发制作；由用户自行从更多菜单选择 OCR / LLM / TTS 继续。
- LLM 总结绘本：OCR 成功后自动调用 LLM 生成绘本名称（替换默认命名）和绘本要点（追加为要点图片参与播放）；LLM 失败不阻断主流程。
- 相机：右下角展示上一张拍摄图片的圆形缩略图（50x50pt），未拍摄时隐藏。
- 播放：点击播放 → 弹出 PlayView 全屏播放当前会话，大图与文字、音频几乎同步。
- 断点继续：当 OCR 结果已存在时，可直接从 LLM 或 TTS 继续后续完整流程；制作失败后保留当前中间状态和草稿记录，不自动清空，支持继续制作或再次保存。
- 未完成记录：未完成记录（如OCR/TTS失败）支持保存，带特殊标记，不允许播放，允许查看、编辑和重新制作；草稿记录需保留已完成的文本、统计信息和阶段状态。
- 后台制作：OCR+LLM+TTS 自动转入后台执行，完成后自动更新会话记录；支持多个后台制作任务并发执行，但 OCR 阶段因外部 API 限制需跨任务串行；记录列表中制作状态展示进度百分比。制作过程独立为页面，顶导重置为制作过程专用导航（含停止按钮）。支持停止制作任务，停止后清空除图片外的其它状态（OCR 文字、TTS 音频等）；制作中的后台记录可加载到前台继续查看或处理。
- 音频分段：长文本 TTS 支持按段合成，以单张图片文字为最小原子聚合；播放时仍按单条记录体验呈现，并保持音频与图片同步翻页；分段信息需随记录保存，并参与导入导出、传输和详情展示。

### 4.5 管理
- 顶导：标题「管理」，无返回按钮、无左侧返回手势；顶导左侧按钮切换分组维度（平铺/系列/月份），默认平铺不持久化。
- 记录管理：支持查看/编辑/删除，不允许播放。支持绘本分组展示，分组内折叠手风琴样式、默认折叠、只能展开一个组；系列按名称排序，未命名放到最后。记录编辑完成后返回列表时，回到进入编辑页前的位置。多选记录时展示更多按钮，更多菜单包括导出和删除。
- 记录编辑：记录编辑页支持头像和封面图片编辑（头像在左、封面在右，位于名称下方），支持旋转（逆时针）和裁剪。
- 记录搜索：搜索框默认不被顶导遮盖（区别于首页 embedded 模式被顶导遮盖），支持名称搜索和系列筛选，与首页共用搜索组件。
- 离开 Tab 重新进入时页面状态重置。

### 4.6 我的
- 顶部头像与简介。
- 菜单分组：第一组为阅读报告、播放设置、播放历史；第二组为要点图片、制作设置、制作历史；第三组为调试日志、实时监控、更新记录、关于。关于页面底部展示隐私条款链接。
- 阅读报告：位于播放历史上方同组，展示听读统计数据。顶部英雄区突出近30天累计时长；支持每周/每月/半年周期切换（Segmented Picker）；指标卡片展示所选周期内的播放时长、听书本数（按名称去重）和听读天数；阅读统计直方图展示天级/周级/月级听书本数（默认天级可切换），以及小时时段听书本数分布；最爱重听 Top3 列表按播放次数降序，带排名徽章。数据来源为播放历史记录。最近收听列表位于最爱重听下方，按时间倒序展示所选周期内所有播放记录，支持分页，行尾展示播放日期。
- 实时监控：APP 级监控指标（CPU、Memory、Disk、Network）时序图，位于调试日志上方同组；打开APP后即启动监控采集，无需进入监控页面。
- 播放历史：保存每次播放记录，展示时按名称去重计数、按最近播放时间倒序；无名称或含「未命名」「测试」字样的不记录且剔除；存储在会话记录中（history.json），随会话导入导出。
- 制作历史：记录保存时间线；无名称或含「未命名」「测试」字样的不记录且剔除；存储在会话记录中（history.json），随会话导入导出。
- 调试日志：按时间倒序展示，简化时间格式，支持展开详情，支持选中特定文字并复制。
- 身份名称：支持简单的身份名称（默认设备名称，可自定义），用于制作/播放历史的发起者标识。

### 4.7 其它
- 配置：运行时配置为应用沙箱 Documents 目录中的 config_local.json，首次由 `PhotoTTS/Resources/config_example.json` 初始化；设置页可编辑配置。
- Siri 语音控制：支持语音指令播放绘本，如「在PhotoTTS中 播放绘本」，通过 App Intents 实现，模糊匹配记录名称。播放中支持通过 Siri 暂停/继续，支持系统音量控制。
- E2E设备间传输：支持通过MultipeerConnectivity在设备间直接传输记录；发送方选择记录后发现附近设备直连传输，选择记录时支持全选/本页/反选；支持两种模式：完整记录传输、仅播放记录传输（仅传输 history.json）。完整记录模式下，发送方自动跳过接收方已存在的记录；仅播放记录模式下，接收方覆盖本地播放历史。接收方收到传输邀请时自动暂停当前播放；传输/接收相关页面为公共组件，支持多入口调起。

## 5. 非功能与约束

- 平台：iOS，iPhone / iPad，竖屏为主。
- 体验：绘本播放连贯，从首页打开、播放、然后返回；制作/播放状态分离，避免误操作。
- 数据：绘本记录支持全量导出/导入及单条记录独立导出；导入按记录 ID 去重，重复 ID 不导入。播放历史与制作历史随会话记录一起导出/导入。
- 播放互斥：任意时刻只允许一个记录播放。
- 列表加载：首页卡片列表采用单页懒加载，管理页维持分页；批量长度为每行卡片数 x10（iPhone 20 条，iPad 30 条）。
- 适配：iPhone / iPad 使用统一比例常量进行页面尺寸适配。
- 版本：MARKETING_VERSION 与 CURRENT_PROJECT_VERSION 自动同步 `PhotoTTS/Resources/changelogs.md` 的最高版本号。
