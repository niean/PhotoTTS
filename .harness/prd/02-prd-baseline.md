# 产品需求 - 稳定固化(不频繁变更)

## 1. 极简摘要

- 产品：PhotoTTS（拍照阅读）— 拍照/选图 → OCR → TTS → 播放语音。
- 用户：3～10 岁儿童及家长，场景为纸质绘本听读与重复收听。
- 结构：底导四个功能Tab（首页、制作、消息、我的）。首页 = 制作入口 + 会话记录列表，点击记录在首页全屏 PlayView 播放；制作 Tab = 拍照/选图 → OCR → TTS → 保存，播放统一用 PlayView 全屏。
- 核心流程：选图（拍照或选图） → 识别(OCR) → 合成(TTS) → 播放 → 保存记录 → 重复播放。

产品定位、体验原则与判断准则见 prd/01-prd-sense.md。

---

## 2. 页面结构

加载页 → 主界面（全屏：播放 / 相机；底导：首页、制作、消息、我的）；各 Tab 内为顶导 + 手势区 + 内容。页面结构如下，

- 全屏容器
    - 启动页
    - 播放(大图)
    - 相机
- 顶状态栏
- 底导Tab
    - 首页
    - 制作
    - 消息
    - 我的
        - ${常规页面}/画布(CustomZStack)
            - ${内容}
            - 顶导
            - 左导(手势识别)

## 3. 功能需求

### 3.1 全屏
- 全屏：播放统一在 PlayView 全屏（护眼底、大图、进度与操作栏）；控制层含底部播放控制区和顶部控制栏；播放设置面板默认隐藏，点击更多按钮后展示。支持双击切换暂停/播放；播放时禁止手动左右滑页，暂停时允许；暂停滑动图片后再播放，音频从当前图片对应位置开始。支持滑动手势调整音量和亮度。相机为全屏 overlay，拍完图加入列表不退出。

### 3.2 底导
- 底导：首页、制作、消息、我的；全屏仅播放(PlayView)与相机 overlay 时遮盖底导。

### 3.3 首页（记录）
- 顶导：标题「首页」。
- 制作入口：拍照制作、选图制作；点击后切到制作 Tab，并打开相机或选图（选图为全屏弹窗）。
- 会话记录：下半段嵌入式会话记录列表（仅展示播放按钮，不展示更多按钮）；点击某条 → 在首页全屏弹出 PlayView 播放（不切制作 Tab）；关闭 PlayView 后仍在首页。
- 默认绘本：内置示例绘本，除播放外不允许任何其它操作（编辑、删除等），不出现在播放历史和制作历史中。
- 记录搜索：支持按名称模糊搜索，搜索框在列表顶部、随列表滚动、默认隐藏需下拉露出。
- 记录分页：每页最多 20 条，底部支持分页切换，按需加载。
- 记录播放入口使用播放图标。
- 拍照/选图从首页发起：若结果为空或取消，关闭后自动回到首页。

### 3.4 制作
- 顶导：标题「制作」；右上角蓝色加号更多（拍照、保存、删除）。
- 制作：拍照制作、选图制作（与首页入口一致）；选图用 MultiImagePicker，完成后写入当前页。之后选择识别，制作阶段为 OCR→LLM→TTS：OCR/LLM（支持豆包、OpenAI Compatible，通过配置文件切换）+ TTS（支持火山引擎、阿里千问，通过配置文件切换）。支持从记录管理加载已有记录到制作页，重新进行 OCR+LLM+TTS。
- LLM 总结绘本：OCR 成功后自动调用 LLM 生成绘本名称（替换默认命名）和绘本要点（追加为要点图片参与播放）；LLM 失败不阻断主流程。
- 相机：支持前后摄像头切换。
- 播放：点击播放 → 弹出 PlayView 全屏播放当前会话，大图与文字、音频几乎同步。
- 后台制作：OCR+LLM+TTS 自动转入后台执行，完成后自动更新会话记录；只允许1个后台制作任务；记录列表中制作状态展示进度百分比。支持停止制作任务，停止后清空除图片外的其它状态（OCR 文字、TTS 音频等）。

### 3.5 消息
- 分组入口：播放历史、制作历史、实时监控、调试日志、更新记录。
- 实时监控：APP 级监控指标（CPU、Memory、Disk、Network）时序图，位于调试日志上方同组。
- 播放历史：保存每次播放记录，展示时按名称去重计数、按最近播放时间倒序；无名称或含「未命名」「测试」字样的不记录且剔除；存储在会话记录中（history.json），随会话导入导出。
- 制作历史：记录保存时间线；无名称或含「未命名」「测试」字样的不记录且剔除；存储在会话记录中（history.json），随会话导入导出。
- 调试日志：按时间倒序展示，简化时间格式，支持选中特定文字并复制。

### 3.6 我的
- 顶部头像与简介。
- 菜单：设置、关于（同组，关于页面底部展示隐私条款链接）；记录管理（独立分组，打开记录列表页，仅查看/编辑/删除，不允许播放）。
- 身份名称：支持简单的身份名称（默认设备名称，可自定义），用于制作/播放历史的发起者标识。

### 3.7 其它
- 配置：配置见 `config_local.json`，设置页可编辑配置。
- Siri 语音控制：支持语音指令播放绘本，如「在PhotoTTS中 播放绘本」，通过 App Intents 实现，模糊匹配记录名称。播放中支持通过 Siri 暂停/继续，支持系统音量控制。

## 4. 非功能与约束

- 平台：iOS，iPhone / iPad，竖屏为主。
- 体验：绘本播放连贯，从首页打开、播放、然后返回；制作/播放状态分离，避免误操作。
- 数据：绘本记录支持全量导出/导入及单条记录独立导出；导入按记录 ID 去重，重复 ID 不导入。播放历史与制作历史随会话记录一起导出/导入。
- 播放互斥：任意时刻只允许一个记录播放。
- 适配：iPhone / iPad 使用统一比例常量进行页面尺寸适配。
- 版本：MARKETING_VERSION 与 CURRENT_PROJECT_VERSION 自动同步 Resources/changelogs.md 的最高版本号。
