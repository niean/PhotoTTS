# Subagent: 扫描日志规范

## 任务

扫描项目源代码，检查日志输出是否符合规范。逐文件读取并检查，输出违规清单。

## 输入参数

- {files}：需要扫描的文件路径列表（可选）。提供时仅扫描指定文件；未提供时扫描下方"默认扫描范围"中的全部文件。

## 默认扫描范围

读取 /Users/niean/code/github.com/niean/PhotoTTS/PhotoTTS/Sources/ 目录下全部 .swift 文件。

## 检查规则

1. 禁止 print() -- 日志输出禁止使用 `print()`，必须统一使用 `os.Logger`（Apple Unified Logging）。分类定义在 PhotoTTSApp.swift 的 `extension os.Logger` 中。
2. 日志内容禁止润色 -- 日志内容禁用 emoji 图标、加粗、斜体等润色，使用普通文字。
3. 错误信息分两层 -- 面向用户的提示使用中文自然语言、不含技术细节；面向开发者的日志使用 `os.Logger`，可包含错误码和上下文。
4. 日志禁止输出敏感信息 -- 日志中禁止输出 API Key、Access Key、Token 等敏感字段；如需标识密钥，仅输出末四位（如 `key=***abcd`）。

## 输出格式

```
## 日志规范 扫描结果

违规数量：N

| # | 文件 | 行号 | 违规项 | 建议修复 |
|---|------|------|--------|---------|
| 1 | ... | ... | ... | ... |

未发现违规的检查项：...
```
