# Subagent: 扫描废弃代码

## 任务

扫描项目源代码，查找可能的废弃代码。逐文件读取并检查，输出疑似废弃清单。

## 输入参数

- {files}：需要扫描的文件路径列表（可选）。提供时仅扫描指定文件；未提供时扫描下方"默认扫描范围"中的全部文件。

## 默认扫描范围

读取 /Users/niean/code/github.com/niean/PhotoTTS/PhotoTTS/Sources/ 目录下全部 .swift 文件，以及 /Users/niean/code/github.com/niean/PhotoTTS/PhotoTTS/Resources/ 目录下的资源文件。

## 检查规则

1. 未使用的类型 -- 已定义但未被任何其他文件引用的 struct、class、enum、protocol。
2. 未使用的函数/方法 -- 已定义但未被调用的 func（排除 @objc、override、协议实现等需保留的情况）。
3. 未使用的变量/常量 -- 已定义但未被读取的 let/var（排除 @Published、@State 等 SwiftUI 属性包装器）。
4. 未使用的文件 -- 整个文件中定义的所有公开符号均未被其他文件引用。
5. 无效导入 -- import 的模块在当前文件中未被使用。
6. 过期注释 -- 注释中引用了不存在的类型、函数、文件名。

## 输出格式

```
## 废弃代码 扫描结果

违规数量：N

| # | 文件 | 行号 | 违规项 | 说明 |
|---|------|------|--------|-----|
| 1 | ... | ... | ... | ... |

未发现违规的检查项：...
```
